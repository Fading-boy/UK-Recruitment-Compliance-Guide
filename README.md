# UK Recruitment Compliance Presentation

This repository contains a slide-based presentation on UK recruitment compliance processing.

## Open the deck
- Open `presentation.html` in a browser to view the presentation.

## Topics covered
- Identity verification
- Right to Work and visa sponsorship
- DBS and overseas police checks
- Occupational Health clearance
- References and gap checks
- Professional registration
- Key decision flow and compliance reminders
